Project Overview

The Task Management App is a productivity tool designed to help individuals and teams organize their daily workflows. It features an intuitive drag-and-drop interface inspired by Kanban boards.

Users can create multiple boards, add tasks, set due dates, assign priority levels, and track progress through visual charts. The app syncs in real-time across multiple devices using Firebase.

Technologies Used

  • JavaScript (ES6+)
  • Firebase Auth
  • Firestore
  • Tailwind CSS
  • Chart.js
  • HTML5
