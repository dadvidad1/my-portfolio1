Project Overview

This weather dashboard provides users with real-time weather information and a 5-day forecast for any city in the world. It utilizes the OpenWeather API to fetch accurate meteorological data.

The interface is clean and minimalist, using dynamic backgrounds that change based on the current weather conditions (e.g., sunny, rainy, snowy). It also stores the user's search history locally for quick access.

Technologies Used

  • HTML5
  • CSS3 (Flexbox/Grid)
  • JavaScript (Fetch API)
  • OpenWeather API
  • Local Storage
  • Lottie Animations
