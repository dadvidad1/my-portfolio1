# ZYAN Portfolio Website

Isang modernong portfolio website na ginawa gamit ang HTML, CSS, at JavaScript. Nagtatampok ito ng sleek dark theme na may mint green accents.

## Mga Tampok
- **Responsive Design**: Gumagana nang maayos sa desktop, tablet, at mobile.
- **Project Detail Pages**: Bawat proyekto ay may sariling pahina para sa mas detalyadong impormasyon.
- **Custom UI**: Glowing elements, geometric backgrounds, at smooth transitions.
- **Contact Form**: Isang functional na contact section para sa mga katanungan.

## Paano Gamitin
1. I-clone ang repository na ito.
2. Idagdag ang iyong sariling mga larawan sa `img/` folder:
   - `myphoto.jpg`
   - `logo.png`
   - `project1.jpg`, `project2.jpg`, `project3.jpg`
   - `project_overview1.jpg`, `project_overview2.jpg`, `project_overview3.jpg`
3. Buksan ang `index.html` sa iyong paboritong browser.

## Tech Stack
- HTML5
- CSS3 (Custom Variables, Grid, Flexbox)
- JavaScript (Vanilla JS)
- Font Awesome (Icons)
- Google Fonts (Poppins)
